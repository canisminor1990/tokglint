# 项目层规则

## UM-01 设置窗口是桌面控制台

用户从托盘打开这个窗口，目的是改挂件，不是浏览产品介绍。

新页面必须服务「看状态」「改显示」「排障」之一。落地页式首屏、眉题和营销大标题不进这个窗口。

## UM-02 挂件不在 React 里重画

挂件绘制和任务栏嵌入在同一进程的 Rust 侧。设置保存后通知该线程。

React 只编辑设置和诊断。不要在设置窗口里做第二套挂件画面来代替真实挂件。

## UM-03 默认挂件用中性用量条

默认主题（`classic-usage-widget`）是任务栏里的连续用量条：数字与进度填充用中性色；提供商身份靠图标区分，不用彩虹品牌色填条。读不到显示 `--`，失败不显示 `0%`。托盘数字徽章可以保留品牌底色。
